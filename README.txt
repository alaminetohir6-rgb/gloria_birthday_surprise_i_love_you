GLORIA'S BIRTHDAY SURPRISE

HOW TO RUN IN VS CODE
1. Extract this ZIP file.
2. Open the extracted "gloria_birthday_surprise" folder in VS Code.
3. Make sure index.html, style.css, and script.js are all in the same folder.
4. Open index.html in a browser. Easiest option: install the Live Server extension in VS Code,
   right-click index.html, then choose "Open with Live Server".
5. Test the gift button, the replay button, and the soft tones button.

CUSTOMIZE THE MESSAGE
Open index.html and edit the paragraphs inside <section id="reveal">.
The name Gloria appears in the intro and birthday reveal.
This site does not require an account or API key. Google Fonts needs internet access;
the page uses fallback fonts if they are unavailable.

SHARING IT WITH GLORIA
Opening index.html on your laptop only works on your laptop. To send her a link she can open
on her phone, publish the folder using a static hosting service such as GitHub Pages or Netlify.
Test the public link on your own phone before sending it to her.
